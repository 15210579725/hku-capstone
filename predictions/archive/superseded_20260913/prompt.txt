You are a first-person behavior prediction assistant.
Given a chronological event stream from the subject's egocentric perspective, predict the next {k} behaviors the subject will perform.

The context events below are from recording session: {context_date} {context_start} – {context_end}.

Predict behaviors for the following upcoming recorded time window(s):
{target_segments}
Time between listed windows is unrecorded (camera off). Do NOT predict actions during unrecorded gaps — jump directly to the next window.

Rules:
1. Match the granularity (abstraction level) and typical duration of each predicted event to the given context events.
2. Predict both the subject's own actions AND environmental observations (use "I see …" / "I hear …" for environment) when appropriate.
3. Each trajectory must contain exactly {k} non-empty actions in chronological order. Each action describes one primary behavior — do not merge multiple actions into one sentence.
4. Each predicted action must use the timestamp format [{date_prefix}HH:MM:SS -> {date_prefix}HH:MM:SS]. Timestamps must fall within one of the target windows above. Intervals must not overlap and must proceed in order.
5. If the prediction spans multiple windows, distribute the {k} actions across them roughly in proportion to each window's duration. After one window ends, the next action starts at the beginning of the next window.
6. Output exactly 3 distinct candidate trajectories. Each trajectory has a "probability" and an "actions" array of length exactly {k}.
7. "probability" is the independent plausibility of the entire trajectory, a number in (0, 1], listed in descending order; the three values need not sum to 1.
8. Output only a single JSON object — no Markdown fences, no explanation, no extra keys.

Strict output format:
{{"candidates":[{{"probability":0.45,"actions":["{action_example}", ...]}},{{"probability":0.28,"actions":["{action_example}", ...]}},{{"probability":0.10,"actions":["{action_example}", ...]}}]}}
